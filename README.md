# Doua-Khatm — Dou'a Khatm al-Qur'an 30

Application web moderne pour maîtriser l'invocation de clôture du Saint Coran (**دعاء ختم القرآن الكريم**) en 30 jours, phrase par phrase.

## Fonctionnalités Clés
- **Bascule 1 clic Singulier / Pluriel** : Réciter seul (Singulier) ou en groupe / famille (Pluriel).
- **Multilingue** : Arabe vocalisé avec tashkîl, phonétique, traductions française et anglaise.
- **Parcours guidé en 4 étapes** :
  1. *Écouter & Réciter* (Audio TTS arabe, mode Shadowing mains-libres).
  2. *Vocabulaire & Sagesse* (Mots-clés cliquables avec prononciation + méditation).
  3. *Quiz de Mémorisation* (Puzzle interactif de reconstitution).
  4. *Studio Micro* (Enregistrement vocal pour comparer sa prononciation + validation XP).
- **Studio de Répétition en boucle** & **Flashcards 3D**.
- **Lecture intégrale synchronisée**.
- **Design Mushaf royal** & mode sombre / clair.

## Lancer le projet
```bash
./start.sh
```
Ou avec Python :
```bash
python3 -m http.server 8091
```
